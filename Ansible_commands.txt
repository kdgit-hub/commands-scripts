/*Basic playbook*/
yaml/yml script (yet another markup language) - extension will be .yml/.yaml

Playbook - 3 parts - 
1) play/target -> where it should get executed 
2) variables
3) tasks 

mkdir playbook
vi filedir.yaml

- hosts: node1
  tasks:
   - name: Create a directory if it does not exist
     ansible.builtin.file:
       path: /opt/kishore_ansible
       state: directory

   - name: Create a file under opt directory
     ansible.builtin.file:
       path: /opt/file1
       state: touch


/*validate playbook - syntax check*/
ansible-playbook filedir.yaml --syntax-check 

/*dry run*/
ansible-playbook filedir.yaml --check 

/*actual execution*/
ansible-playbook filedir.yaml -> first it checks in the inventory whether the mentioned hosts exist or not, check in target node file and directory created


-- NOTE: if we want to delete the above file and directory then just change the state: absent

/*create a playbook for installing apache webserver*/
-- Manual approach

for Apache webserver on RHEL/CENTOS/Fedora we need to install a package -> httpd i.e. yum install httpd
for Apache webserver on ubuntu we need to install a package -> apache2 -> apt install apache2

cat /etc/os-release -> O.S flavour - RHEL
yum update -y
yum install httpd -y -> install apache webserver 
systemctl start httpd -> start apache webserver 
systemctl enable httpd -> enable apache webserver at boot level 
systemctl status httpd  -> 

check from browser ->  //publicip:80 -> default apache static page will be displayed

/var/www/html -> default location -> vi index.html -> we can play the game 


-- write a playbook to automate the above process
 
mkdir playbook
vi apache.yaml

- hosts: node1
  tasks:
   - name: install apache web server
     ansible.builtin.dnf:
       name: httpd
       state: latest
       update_cache: yes

   - name: start httpd service, if not started 
     ansible.builtin.service:
       name: httpd
       state: started
       enabled: yes

   - name: copy the customer website into web server 
     ansible.builtin.cpy:
       src: /root/playbook/index.html
       dest: /var/www/html


/*validate playbook - syntax check*/
ansible-playbook apache.yaml --syntax-check 

/*dry run*/
ansible-playbook apache.yaml --check 

/*actual execution*/
ansible-playbook apache.yaml -> it installs apache web server
