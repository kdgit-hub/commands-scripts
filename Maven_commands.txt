- server reboot

--------------------------------------------------------------------

mvn clean -> cleans the project by deleting the target directory (.war/.jar/.ear)
mvn validate -> validates the project structure and configuration before the actual build starts (like it validates pom.xml file etc.)
mvn compile -> compiles the source code of the project located in src/main/java (app.java -->convert to --> app.class)
mvn test -> runs the unit tests for the project using JUnit 
mvn package -> packages the compiled code into .JAR/.WAR/.EAR file (artifacts)
mvn verify ->  verify the integration checks for artifact (.JAR/.WAR)
mvn install -> installs the packaged artifact(project) into local repo Location usually in user home directory: /.m2/repository  (.WAR will store in .m2 folder)
--note: if we run directly mvn install then it will run mvn package command also
mvn deploy -> deploys the project/artifact to a remote repo (like Nexus/JFrog/S3/Azure storage)

NOTE: mvn clean deploy -> means it runs all steps from clean to deploy and mvn deploy -> means it will run all steps from validate to deploy
